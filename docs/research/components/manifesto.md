# Component Spec — Manifesto

## Nome
Manifesto / Tagline Block

## Estrutura DOM
```
section.manifesto
  div.container
    h2 → "Less structure, more intelligence."
```

## Layout
- Centered, narrow container
- Max-width: ~640px
- Padding vertical: ~100–140px

## Estilos
- H2: 32–40px, weight 600–700, line-height 1.2
- Cor: #111 ou similar
- Text-align: center

## Mobile
- Font-size reduzida para ~28px
- Padding vertical ajustado
